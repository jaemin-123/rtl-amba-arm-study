## 3. 핵심 개념

- **SISO**(Serial-In, Serial-Out)는 입력과 출력이 모두 한 비트다. 매 상승 에지에 `sin`이 `q[0]`에 들어가고, 이전 값은 상위 비트로 한 칸씩 이동한다. 직렬 출력은 `assign sout = q[7];`로 연결한다.
- **Active-low 동기 리셋**은 상승 에지에서 `rst_n=0`이면 전체 상태를 0으로 만든다. 교재의 `rst`를 여기서는 극성을 드러내도록 `rst_n`으로 쓴다.
- **Enable**은 Day08에서 이어가는 확장이다. 리셋이 우선하고, 리셋이 해제된 상태에서 `en=0`이면 8비트 전체를 유지한다.
- **Nonblocking**은 각 단계가 에지 직전의 값을 읽도록 한다. Day07의 4단 실습과 같은 원리다.

## 4. Verilog 실습

1. `rtl/shift_reg_bits.v`에서 `q[0] <= sin;`과 `q[1] <= q[0];`부터 `q[7] <= q[6];`까지 작성한다. 포트는 `clk`, `rst_n`, `sin`, `sout`으로 두고 내부 상태는 `reg [7:0] q;`로 선언한다.
2. `rtl/shift_reg_concat.v`에서 같은 동작을 `q <= {q[6:0], sin};`으로 표현한다. 두 모듈 모두 `always @(posedge clk)`에서 리셋을 먼저 검사한다.
3. `tb/tb_shift_reg.v`에서 두 모듈에 같은 입력을 연결한다. Vivado 파형에 내부 `q`와 `sout`을 추가한다. 상승 에지 한 번 동안 리셋을 유지하고, 하강 에지에서 리셋을 해제하며 `sin=1`을 준다. 다음 하강 에지부터 `sin=0`을 유지한다.

| 입력을 받은 에지부터 센 번호 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|---|---|---|---|---|
| 에지 직후 q (hex) | 01 | 02 | 04 | 08 | 10 | 20 | 40 | 80 | 00 |
| sout | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 1 | 0 |

입력을 받은 첫 에지를 포함하면 8번째 에지에서 출력이 1이고, 첫 에지부터의 시간 차이는 7클록 주기다.

4. 결합 연산자 버전을 `rtl/shift_reg_en.v`로 복사해 `en`을 추가한다. `q=04`에서 하강 에지에 `en=0`을 주고 상승 에지 두 번 동안 `04` 유지, `en=1`로 돌아온 다음 상승 에지에 `08`을 확인한다. 이후 다시 멈춘 상태에서 `rst_n=0`을 주어 다음 상승 에지에 0으로 초기화되는지 확인한다.

## 5. SystemVerilog 자동 검증

`rtl/shift_reg_en_sv.sv`에서 포트와 상태를 `logic`으로 선언하고, `always_ff @(posedge clk)` 안에서 아래 순서로 상태를 갱신한다.

```systemverilog
if (!rst_n)
    q <= 8'h00;
else if (en)
    q <= {q[6:0], sin};
```

`tb/tb_shift_reg_en_sv.sv`에서 Verilog와 SV에 같은 입력을 준다. 첫 리셋 상승 에지부터 아래 검사를 실행한다. 입력과 검사를 별도의 `initial` 블록에서 실행한다. 입력은 하강 에지에서 바꾸고, `expected`는 첫 리셋 상승 에지에서 0으로 초기화한다.

```systemverilog
@(posedge clk);
if (!rst_n)
    expected <= 8'h00;
else if (en)
    expected <= (expected << 1) | {7'b0, sin};

#1;
assert ((sout_v === sout_sv) && (sout_sv === expected[7]))
    else $fatal(1, "Shift mismatch at %0t", $time);
```

이 검사를 필요한 상승 에지마다 반복하고 마지막에 `$finish;`를 호출한다. 직렬 출력 비교와 함께 내부 `q` 파형에서 이동·정지·리셋 시점도 확인한다.

## 6. 선택 확장

- 슬라이드 11의 `for` 반복문으로 비트별 할당을 줄여 본다.
- 슬라이드 11의 시프트 연산자 예제에서 `q <= q << 1;`과 `q[0] <= sin;`의 순서를 바꿔 비교한다. 두 할당이 모두 `q[0]`에 쓰므로, 전체 벡터 할당을 마지막에 쓰면 그 비트는 시프트 결과인 0이 된다.
- 이번 기대값 계산은 SV TB에서 다룬다. C 실습은 ARM 소프트웨어 단계에 배치한다.

## 7. 검증 결과

| 항목 | 예상 결과 | 실제 결과 |
|---|---|---|
| 단발 입력 | 8번째 시프트에서 sout=1 | 비트별·결합 버전 모두 30ns에 1을 받고 170ns에 sout=1, 190ns에 0 |
| Enable 정지·재개 | 04 유지 후 08로 이동 | 90ns와 110ns에 04 유지, 130ns에 08, 210ns에 sout=1 |
| 동기 리셋 우선 | en=0에서도 다음 상승 에지에 q=00 | 310ns에 04 유지, 320ns에 리셋을 걸어도 04 유지, 330ns에 00 |
| Verilog/SV 자동 비교 | 두 직렬 출력과 expected[7] 일치 | 초기 리셋과 정상 시프트에서 상승 에지 15회 통과. 로그 `match` |

Enable 정지·재개와 리셋 우선순위는 Verilog 파형으로 확인했다. SV 자동 검사의 범위는 초기 리셋과 정상 시프트의 직렬 출력이다.

## 8. 에러 및 해결

- **리셋 방식** — 처음 비트별·결합 버전은 `negedge rst_n`을 포함한 비동기 리셋으로 시프트 동작을 확인했다. 교재의 동기 리셋은 `always @(posedge clk)`를 사용하며, Enable 버전에서 상승 에지에 초기화되는 것을 확인했다.
- **테스트벤치 검사 시작 시점** — 한 `initial`에서 입력 지연을 먼저 실행하니 검사가 50ns부터 시작해 10ns 리셋 에지를 놓쳤다. 또 `en`이 0에 머물러 30ns에 입력한 1이 저장되지 않았다. 입력과 검사를 별도 `initial`로 분리하고 리셋 해제 시 `en=1`을 설정했다. 수정 후 10ns부터 검사해 15회 통과했다.

## 9. 학습 내용 및 다음 보완

- `(expected << 1) | {7'b0, sin}`은 기존 상태를 한 칸 밀고 비트별 OR로 최하위 비트에 `sin`을 넣는다. 이 표현은 Verilog RTL에서도 사용할 수 있다.
- 기대값에 `<=`를 쓰면 같은 시각의 NBA 단계에서 갱신된다. 이번 TB는 `#1;` 뒤에 비교하므로 갱신된 값을 읽는다.
- 추가 검증으로 Enable 정지·재개와 리셋 우선순위를 SV 검사 입력에도 포함할 수 있다.
